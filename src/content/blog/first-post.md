## 문제 상황

어떤 작업을 하던 중, 어떤 증상이 나타났나요? 실행 환경과 예상했던 동작을 함께 적습니다.

## 재현 방법

문제가 발생하는 최소한의 조건을 정리합니다. 필요한 코드와 로그를 함께 남깁니다.

```js
// 실제로 문제를 재현하는 코드로 바꿔주세요.
const result = await fetch('/api/example');
console.log(result.status);
```

## 원인을 좁혀간 과정

처음 세운 가설과 그것을 확인한 방법을 적습니다. 맞지 않았던 가설도 근거와 함께 남겨보세요.

### 확인한 근거

- 재현 결과
- 로그 또는 실행 계획
- 참고한 공식 문서
